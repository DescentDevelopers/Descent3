Descent 3 for Android

Upload game data

Your device needs the data files from a Descent 3 installation. Choose the game's install folder — the one that contains d3.hog — and upload it.

Where to find it

Windows

  • SteamC:\Program Files (x86)\Steam\steamapps\common\Descent 3
  • GOG GalaxyC:\Program Files (x86)\GOG Galaxy\Games\Descent 3

In the folder picker, paste the path into the address bar at the top and press Enter.

macOS

  • Steam~/Library/Application Support/Steam/steamapps/common/Descent 3/Descent 3.app/Contents/Resources

In the folder picker, press ⌘⇧G, paste the path and press Return. (The folder is inside the app bundle, so you can't click your way there.)

Linux

  • Steam (Fedora, Arch, …)~/.local/share/Steam/steamapps/common/Descent 3
  • Steam (Debian, Ubuntu, …)~/.steam/debian-installation/steamapps/common/Descent 3
  • System-wide install/usr/share/descent3
  • Local install/usr/local/share/descent3

In the folder picker, press CtrlL, paste the path and press Enter. (The Steam folders are hidden, so they won't show up when browsing.)

Installed somewhere else? In Steam, right-click Descent 3 → Manage → Browse local files. In GOG Galaxy, open Descent 3 → the settings icon → Manage installation → Show folder.
